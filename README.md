# POE2 Price Checker

เช็คราคาไอเทมและบิว Path of Exile 2 ด้วยราคาสดจาก poe.ninja และเทรดไซต์ทางการ ผ่านหน้าเว็บที่รันบนเครื่องของคุณเอง

## ดูราคาออนไลน์ทันที (เว็บ)

**https://ztheyutz.github.io/poe2-price-checker/**

ค้นราคาไอเทมทุกตัวที่ poe.ninja มี ไม่ต้องล็อกอิน ไม่ต้องติดตั้ง (อัปเดตทุกชั่วโมงโดย GitHub Actions)
เวอร์ชันเว็บนี้มีแค่แท็บค้นหาไอเทม — ถ้าจะวางไอเทมจากเกม เช็คทั้งบิว หรือหาร้าน ใช้ Codespaces หรือติดตั้งบนเครื่องตามด้านล่าง

## ใช้บน GitHub เลย ไม่ต้องติดตั้ง (Codespaces)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/zTHEYUTz/poe2-price-checker?quickstart=1)

1. ล็อกอิน GitHub แล้วกดปุ่มด้านบน → **Create codespace**
2. รอ 1–2 นาที (ครั้งแรกจะติดตั้งให้เอง) หน้าเว็บของโปรแกรมจะเปิดในแท็บใหม่
   - ถ้าไม่เปิดเอง: ไปแท็บ **PORTS** ด้านล่าง → คลิกรูปลูกโลกที่พอร์ต **8765**
3. ใช้เสร็จแล้วปิดได้เลย Codespace จะหยุดเองเมื่อไม่ได้ใช้ (~30 นาที)
   เปิดใหม่ได้ที่ https://github.com/codespaces

ข้อควรรู้
- บัญชี GitHub ฟรีใช้ Codespaces ได้ราว 60 ชั่วโมง/เดือน (คิดจากโควตาของคนที่เปิด)
- พอร์ตเป็น **Private** ตามค่าเริ่มต้น (เห็นแค่เจ้าของ) — อย่าเปลี่ยนเป็น Public
- Codespaces ใช้ IP ของ cloud เทรดไซต์ของ GGG อาจบล็อกบางครั้ง ถ้าเป็นแบบนั้น
  ราคา rare / หาร้าน จะใช้ไม่ได้ แต่ราคาจาก poe.ninja ยังใช้ได้ปกติ → ใช้ `start.bat` บนเครื่องตัวเองแทน

## เริ่มใช้งานบนเครื่องตัวเอง (Windows)

1. ติดตั้ง **Python 3.10 ขึ้นไป** จาก https://www.python.org/downloads/
   ตอนติดตั้ง **ติ๊ก "Add python.exe to PATH"** (ทำครั้งเดียว)
2. ดาวน์โหลดโปรเจกต์นี้: กดปุ่มเขียว **Code → Download ZIP** บนหน้า GitHub แล้วแตกไฟล์
   (หรือ `git clone` ถ้าใช้ git เป็น)
3. ดับเบิลคลิก **`start.bat`**
   - ครั้งแรกจะติดตั้งสิ่งที่ต้องใช้ให้เอง (~1 นาที)
   - หน้าเว็บจะเปิดในเบราว์เซอร์อัตโนมัติ (http://127.0.0.1:8765)
   - ปิดหน้าต่างดำเพื่อปิดโปรแกรม

macOS / Linux: เปิด Terminal ในโฟลเดอร์นี้แล้วรัน `./start.sh`

## มีอะไรบ้าง

- **ค้นหาไอเทม** — ตารางราคาทุกตัวที่ poe.ninja มี (ยูนีค / currency / เจม / รูน / soul core ฯลฯ) เรียงตามราคา ปริมาณซื้อขาย หรือ % 7 วันได้ เลือกแสดงเป็น Divine / Exalted / Chaos พร้อมลิงก์ Wiki และ Trade
- **วางไอเทมจากเกม** — ในเกมชี้ไอเทมแล้วกด Ctrl+C แล้ววาง ได้ทุกชนิด รวมถึง rare/magic (ค้นของ mod ใกล้เคียงในเทรด)
- **เช็คทั้งบิว** — วาง PoB code หรือลิงก์ pobb.in / pastebin ดูราคารวมทั้งบิว

- **บิวที่บันทึก** — บันทึกบิวที่เคยเช็คไว้ กดเช็คราคาใหม่ได้ในคลิกเดียว พร้อม**ประวัติราคา** (กราฟ + ตาราง ทุกครั้งที่เช็ค) (เก็บในไฟล์ `saved_builds.json` ในเครื่อง)

ทุกไอเทมมีปุ่ม **วาปไปร้าน** (เปิดเทรดไซต์ทางการ เรียงถูกสุดก่อน → กด Travel to Hideout เอง),
**คัดลอกข้อความซื้อ** และ **รีเฟรช หาร้านใหม่** ถ้าร้านเดิมขายไปแล้ว
ชี้ที่ชื่อร้านเพื่อดู mod ของชิ้นนั้น พร้อมป้าย **Prefix / Suffix และ Tier**
ราคาจาก poe.ninja มี **กราฟแนวโน้ม 7 วัน** และ % ที่ขึ้น/ลง

### บิวจากเว็บอื่น (poe.ninja, maxroll, mobalytics ฯลฯ)
เว็บเหล่านี้กันโปรแกรมภายนอกอ่านหน้าเว็บ จึงวางลิงก์ตรง ๆ ไม่ได้ —
เปิดหน้าบิว → กดปุ่ม Export / PoB → คัดลอกโค้ด → วางในช่องแทน

## ใช้งานผ่าน command line
```
pip install -r requirements.txt
python poe2_price.py "<PoB code>"
python poe2_price.py https://pobb.in/xxxxxx
python poe2_price.py build.xml --league Standard --json result.json
python poe2_price.py "<PoB code>" --no-rares      # เร็ว: ไม่ค้นไอเทม rare
```

## ราคามาจากไหน
| ประเภท | แหล่ง |
|---|---|
| ยูนีค, currency, รูน, soul core, lineage gem, uncut gem | poe.ninja (อัปเดตราว 1 ชม.) |
| ไอเทม rare / magic / jewel | เทรดไซต์ทางการ ค้น **ฐานไอเทมเดียวกันเท่านั้น** ตาม mod (ค่า ≥ 80% ของไอเทม) ไม่รวมของ corrupted (ถ้าของคุณไม่ corrupted) แล้วใช้มัธยฐานของ 10 รายการที่ถูกที่สุด — แต่ละร้านบอกว่ามี mod ตรงกับของคุณกี่ตัว |

## ข้อควรรู้
- ราคา rare เป็นค่าประมาณ ไอเทมที่ mod ดีมาก/หายากอาจประเมินต่ำหรือสูงเกินจริง
- ยูนีคที่มีคนขายน้อยกว่า 5 รายการ ราคาบน poe.ninja อาจไม่จริง (หน้าเว็บจะติดป้ายเตือน)
- เทรดมี rate limit: โปรแกรมอ่านโควตาที่เทรดไซต์แจ้งมาแล้วชะลอเองก่อนเต็ม
  ผลค้นเทรดถูกจำไว้ 5 นาที (ปุ่ม "รีเฟรช หาร้านใหม่" ค้นใหม่จริงเสมอ) บิวที่มี rare 10 ชิ้นอาจใช้ 1–3 นาที
- โปรแกรมเปิดให้เข้าได้จากเครื่องตัวเองเท่านั้น (127.0.0.1)

## ตั้งค่าเสริม (environment variables)
- `POE2_PRICER_UA` — User-Agent ที่มีชื่อแอปและช่องทางติดต่อของคุณ (GGG ขอให้เครื่องมือภายนอกระบุตัว)
- `PORT` — เปลี่ยนพอร์ตของหน้าเว็บ (ค่าเริ่มต้น 8765)
- `POESESSID` — **ไม่แนะนำ** กติกาของ GGG ห้ามเครื่องมือภายนอกใช้คุกกี้ล็อกอินของผู้เล่น
  และห้ามแชร์ค่านี้ให้ใครเด็ดขาด
